# Bivouac instance

This repo describes one Bivouac server: its apps, sites, authorized SSH keys
and encrypted secrets. Git is the source of truth: the reconciler on the
server applies what is on `main` within a minute.

Read the product brief and the decision log in the public monorepo before
changing anything: https://github.com/chamboug/bivouac

Record every action taken on the server in `OPERATIONS.md`.
