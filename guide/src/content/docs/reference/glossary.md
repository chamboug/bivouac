title: Glossary
description: The few internal words bivy shows on screen, one line each.
---

These words appear in what `bivy` prints. Each is explained in one line.

| Word | What it is |
|---|---|
| GHCR | GitHub's container registry, where the platform's versions are published. |
| Pass | One round of the reconciler: it runs every minute. |
| Reconciler | The program on your server that reads your instance repository every minute and makes the server match it: apps, databases, certificates and backups. |
| Renovate | The tool that opens, once a month, the pull requests that update the platform. |
